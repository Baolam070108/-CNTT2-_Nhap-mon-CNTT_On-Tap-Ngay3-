# Dự án Website Trung tâm tiếng anh (TTA)
## Giới thiệu
- Chào mừng bạn đến với **dự án xây dựng và phát triển hệ thống Website chính thức cho Trung tâm tiếng Anh TTA**. Website được thiết kế nhằm *nâng cao trải nghiệm học tập, tối ưu hóa quy trình quản lý học viên và hỗ trợ tuyển sinh hiệu quả*.
## Cấu trúc thư mục

|Thư mục|Nội dung
|-|-|
src/components|Chứa form đăng kí và khóa học của trung tâm tiếng anh
src/pages|Chứa trang chính chủ của trung tâm tiếng anh
src/services|Chứa mã nguồn liên kết với dữ liệu của học viên, thanh toán trực tuyến
src/utils|Chứa các tính năng tiện ích 
## Danh sách đánh số quy trình đăng kí học tại TTA
- Bước 1. Truy cập vào link repository trên Github kèm theo link đường dẫn và tải mã nguồn vào máy 
- Bước 2. Giải nén file và di chuyển vào thư mục đường dẫn của trung tâm tiếng anh
- Bước 3. Chạy lệnh cài đặt các mục cần thiết (chạy trên terminal)
- Bước 4. Khởi chạy trên máy (chạy trên terminal)

- **Code block liệt kê nội dung dự án:** \
`Windows PowerShell: gci -Recurse -Force`\
`Terminal: ls -aR`
